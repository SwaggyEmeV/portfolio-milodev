## Qué es

Mi portfolio personal y mi primer proyecto con Astro. Cada proyecto es un archivo Markdown y Astro genera las páginas al compilar, así que el resultado es HTML puro y muy rápido.

## Cómo lo hice

- **Astro** para los componentes, los layouts y las rutas dinámicas.
- **Tailwind CSS** para el diseño, con una paleta propia: verde terminal y naranja motor sobre negro asfalto.
- **Content collections** para validar los datos de cada proyecto.

## Qué aprendí

- Pensar una web en componentes reutilizables.
- Diseñar con clases de utilidad y de forma responsive (*mobile first*).
