## Qué es

Mi portfolio personal y mi primer proyecto con Astro. El home es un mapa de red: yo soy el objetivo y cada sección es un host. Pulsas un nodo, se hace el *handshake*, el expediente se descifra y queda marcado como comprometido. Si compromete los seis hosts, obtienes root. También hay una consola (tecla `` ` ``) con comandos propios.

## Cómo lo hice

- **Astro** para los componentes, los layouts y las rutas dinámicas.
- **Tailwind CSS** para el diseño, con una paleta propia: negro azulado de monitor, agua marina y rojo solo para alertas.
- **Canvas 2D** para el mapa: física de resortes, radar, paquetes por los enlaces y nodos arrastrables, sin librerías.
- **TypeScript** para la consola, el efecto de descifrado y el tráfico de red simulado.
- **Content collections** para validar los datos de cada proyecto.

## Qué aprendí

- Pensar una web en componentes reutilizables.
- Construir una interfaz interactiva sin framework, solo con el DOM y Canvas.
- Diseñar con clases de utilidad y de forma responsive (*mobile first*).
