## Qué es

Mi portfolio personal y mi primer proyecto con Astro. El home es una terminal: se navega con comandos (`ls`, `cd`, `cat`...) o con el explorador de archivos, y cada proyecto es un archivo Markdown que Astro convierte en página al compilar.

## Cómo lo hice

- **Astro** para los componentes, los layouts y las rutas dinámicas.
- **Tailwind CSS** para el diseño, con una paleta propia: agua marina sobre negro asfalto.
- **TypeScript** para el mini shell del navegador: parsea comandos, resuelve rutas y escribe la salida.
- **Content collections** para validar los datos de cada proyecto.

## Qué aprendí

- Pensar una web en componentes reutilizables.
- Construir una interfaz interactiva sin framework, solo con el DOM.
- Diseñar con clases de utilidad y de forma responsive (*mobile first*).
